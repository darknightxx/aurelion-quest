# Aurelion Quest

เกม 3D Action RPG ผจญภัยในทวีป Aurelion ที่ผสมการต่อสู้เข้ากับการตอบคำถาม เล่นได้ทันทีบนเบราว์เซอร์ ไม่ต้องติดตั้ง

**เล่นเลย:** https://darknightxx.github.io/aurelion-quest/

## จุดเด่น
- 6 อาชีพ แบ่ง 4 สายบทบาท: แทงค์ / โจมตีประชิด / ระยะไกล-นักเวท / สนับสนุน-ฮีลเลอร์
- อาชีพละ 4 สกิลตามบทบาท และสกิลใหญ่ที่ต้องตอบคำถามให้ถูกเพื่อพลัง ×2 อัปเลเวลสกิลได้ถึง 5
- สัตว์ขี่ 13 ชนิด มีความสามารถพิเศษและสกิลต่อสู้ของตัวเอง
- เควสหลัก เควสย่อย เควสรายวัน และนำทางอัตโนมัติ
- บอสพร้อมเกราะผลึกที่ต้องทำลายด้วยการตอบคำถามต่อเนื่อง
- Season Pass, ร้านเพชร, ของแต่งตัว (โหมดทดลอง ไม่มีการตัดเงินจริง)
- รองรับคอมพิวเตอร์และมือถือ บนมือถือจะสลับเป็นแนวนอนอัตโนมัติ

## การควบคุม (คอมพิวเตอร์)
| ปุ่ม | การทำงาน |
|---|---|
| WASD / คลิกพื้น | เดิน |
| Space | โจมตี |
| Q E R T | สกิลตามบทบาท |
| X | สกิลใหญ่ (ตอบคำถาม) |
| 1 / 2 | ยา HP / MP |
| V / G | ขี่สัตว์ / สกิลสัตว์ขี่ |
| P | หน้าสกิล |
| I C L M | กระเป๋า ตัวละคร เควส แผนที่ |
| คลิกขวาค้าง + ลาก / ล้อเมาส์ | หมุนกล้อง / ซูม |

บนมือถือใช้จอยสติ๊กซ้ายล่างและปุ่มสกิลขวาล่าง แตะค้างที่ปุ่มสกิลเพื่อดูรายละเอียด

## หมายเหตุ
- เซฟเกมเก็บในเบราว์เซอร์ของอุปกรณ์ที่เล่น
- ทั้งเกมอยู่ในไฟล์ `index.html` ไฟล์เดียว
